# ElectroHub

ElectroHub is an Android marketplace application for buying and selling
PC components, laptops, gaming hardware, and accessories.

## Features
- User registration and login (Email verification,Forgot password)
- Create and publish product listings
- Upload product images
- Browse products
- View detailed product information
- Save products for later
- Message product owners
- Product categories
- Report inappropriate listings
- User profiles
- Settings (Night/Light mode and language)

## Technologies
- Kotlin
- Android Studio
- XML
- MVVM Architecture
- Repository Pattern
- Navigation Component
- Cloud Firestore
- Cloudinary
- Glide
- DataStore
- Firebase Cloud Functions

## Project Structure

The application follows an MVVM architecture with a Repository pattern.
